## 0. Overview

> A collection of independent Python examples for studying trading strategies and financial models.
>
> - Data inputs and analysis or backtesting methods vary by example, with testing implemented inside individual scripts.

> - Source: [je-suis-tm/quant-trading](https://github.com/je-suis-tm/quant-trading).
> - Studied revision: `master` at [611b73f](https://github.com/je-suis-tm/quant-trading/commit/611b73f2c3f577ac5b28aaa19ac8c43d3236c7a5).
> - Inspected: `2026-10-07`.
